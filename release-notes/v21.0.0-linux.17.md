## Less memory

On Hyprland, sway, niri and KDE Wayland, ShareX now draws its windows in software instead of loading the GPU driver into the tray app. Idle memory drops from about 288 MB to about 192 MB, and the first window opens slightly faster. GNOME and X11 keep GPU drawing. Set `SHAREX_RENDERING=gpu` or `SHAREX_RENDERING=software` to override.

## Bug fixes

- Downloads with no or zero `Content-Length` are no longer skipped, a connection that closes early no longer loops forever, and cancelling a download now stops it.
- Files are now streamed straight to disk instead of being held in memory first (an 8 MB download used to allocate 8 MB).
- Settings saves no longer leave `.temp` files behind after a failure, and a save interrupted by a crash is recovered on the next start.
- Server-supplied download names are cleaned up properly: UTF-8 names work, and names containing paths are rejected.
- Zip extraction refuses entries that would write through an existing symlink outside the target folder.
- Upload errors no longer write URLs, cookies or response bodies (which can contain API keys) to the log file. The full details still appear in the error window.
- OAuth request signing now orders parameters the same way in every system language.
- Filename patterns with nested placeholders are no longer expanded twice, which could corrupt literal text in names.
- External tools (grim, ffmpeg and others) can no longer hang ShareX past their timeout, and finished child processes are cleaned up.
- A filename ending in a very large number in brackets, like `photo (99999999999999999999).png`, no longer crashes unique-name generation.

## Image editor

- Auto-crop is much faster on large images (a 4K screenshot: about 87 ms down to 1 ms).
- Image effect presets no longer leak an image's memory per applied effect.
- Cropping with out-of-range values returns the visible part instead of failing.
- A rejected cut-out no longer clears redo history.
- Saving to a bare filename (no folder) works.

## Smaller cleanups

Six unused files, 63 unused imports and a set of redundant package references were removed. SQLite history inserts are about twice as fast.
