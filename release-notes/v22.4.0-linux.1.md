## ShareX 22.4

This release brings the Linux port up to upstream ShareX 22.4 (the `develop` branch, including 349 commits after the 22.4.0 release). The highlights from upstream:

- **Photo editor (beta):** layers, adjustments and filters, brushes and content-aware retouching. Open it from the Tools menu, from a hotkey, from the history or main window right-click menu, or as an after-capture task.
- **Pixel editor:** pixel art and sprite animations, with layers, tilemaps, palettes and sprite sheet export.
- **OCR:** text recognition now uses PaddleOCR with the PP-OCRv6 models. It runs offline, and the models ship with ShareX. The OCR window shows the image and outlines the recognized text. tesseract is no longer needed.
- **Region capture:** a customizable toolbar that can be made compact and dragged, an option to dim everything except the current selection, a "Capture selected region" mouse action, a border option for the magnifier, secondary toolbar shortcuts, and a classic ruler like the ShareX 21 one.
- **Screen recording:** adaptive GIF output, and the recorder bar now shows crossed-out icons for sources that are off.
- **Also new:** a Stats window built from your local history, WebP output with quality and lossless options, a legacy icon pack with the ShareX 21 icons, and a Spacious / Compact layout choice with spacing sliders.

## Linux

- ShareX now runs on .NET 11, like upstream. Prebuilt releases include the runtime. Building from source needs the .NET 11 SDK, and `install.sh --from-source` fetches it into `~/.dotnet` when it is missing.
- Upstream asks for Windows fonts by name (Segoe UI, Consolas). These now map to your desktop's own sans-serif and monospace fonts, so hashes, logs and FFmpeg command lines line up again.
- Recording works with FFmpeg 9, which made `-thread_queue_size` an output-only option.
- On Hyprland, the recording frame and region outline are see-through instead of black. They are sized correctly on scaled monitors (`xwayland:force_zero_scaling`) and are not blurred, shadowed or bordered by the compositor. The recorder bar sits next to the region instead of off-screen.
- Recording windows float and are placed correctly with a Lua Hyprland config (`hyprland.lua`, Hyprland 0.56 and later).
- OCR, screen recording and pin-to-screen select their region with the native overlay. The fallback overlay no longer selects its own window.
- Monitors are matched by output name, because XWayland can lay them out differently from the compositor.
- The `%pn` (process name) filename pattern gives the real name for Chromium and Electron apps.

## Bug fixes

- `sharex -PhotoEditor`, `-PixelEditor`, `-VideoTrimmer` and `-AnimatedGifTrimmer` now open the file passed to them instead of uploading it.
- Pressing Escape to cancel an annotation in the region overlay no longer also closes the whole capture.
- Custom FFmpeg recording commands keep output folders with spaces or quotes as one argument.
- "Last region" with several regions keeps the right areas on HiDPI Wayland.
- "Capture region (Transparent)" covers the desktop instead of being tiled on Hyprland.
- The Photo and Pixel editors treat `Photo.png` and `photo.png` as different files.
- Without `XDG_RUNTIME_DIR`, the single-instance socket is kept in your cache folder instead of the shared `/tmp`.
- `sharex --doctor` and `--install-binds` can no longer hang on a helper program that does not exit.
