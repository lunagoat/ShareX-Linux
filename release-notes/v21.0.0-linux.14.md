## KDE Plasma: region capture on every monitor

A KDE user reported that the capture overlay showed the left monitor's screen on the right monitor and only allowed screenshots there. KDE support was untested, so this release adds what it was missing:

- Region capture on KDE now covers all monitors, with KWin-scripted placement of the overlay (the result is checked; a single-monitor placement is rejected).
- The cursor position on KDE comes from KWin instead of the X11 query, which is stale under Wayland.
- KDE Wayland uses `slurp` (Plasma 6 supports layer-shell) when it is installed, and falls back to it if the overlay cannot be placed. `sharex --doctor` says which it chose and why.
- KDE monitor sizes were rotated twice; fixed. Verified with fixtures only: real KWin behaviour still needs a KDE user to confirm.

## `sharex --doctor` shows your displays

A new Displays section lists the monitors as ShareX, XWayland and the compositor see them, the pointer position from each, the selector and window-placement path in use, and warns when they disagree. Paste it in bug reports for multi-monitor problems.
